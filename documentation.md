\### Назначение проекта



Проект предназначен для изучения и практики разработки игр на Godot Engine с использованием C# (.NET). В рамках проекта реализуются:

\- Система наследования для игровых объектов (враги, препятствия).

\- Игровая логика персонажа (Player) и снарядов (Bullet).

\- Настройка параметров геймплея через инспектор Godot (амплитуда движения, урон, здоровье, скорость и т.д.).



\### Текущее состояние



На момент написания документации проект находится в состоянии pre-beta. Ведётся работа над веткой `feature`, в которой тестируются альтернативные значения параметров геймплея для летучих мышей, игрока и других объектов.
